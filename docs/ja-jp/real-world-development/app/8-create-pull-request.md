フィルター機能の実装、指示の更新、スキルの更新、品質保証 (QA) プロファイル、テストを1つのブランチに保存しました。これらをまとめてレビューし、pull request を作成しましょう。星評価の pull request (PR) は自分でマージしましたが、今回は **Agent Merge** にプロセスの管理を任せます。

> [!NOTE]
> 通常は、機能、指示の更新、スキルの更新、QA エージェントを複数の PR に分けます。ワークショップを効率よく進めるため、フィルター機能と品質ワークフロー全体を1つのセッションとブランチで進め、すべての作業をこの PR にまとめました。

このレッスンでは、次の操作を行います。

- Agent Merge の概要と、マージのライフサイクルを自動化する仕組みを確認します。
- 機能の PR 全体と検証結果を調べます。
- レビュー後にのみ Agent Merge を承認し、PR がマージされたことを確認します。

## シナリオ

フィルター機能のワークフロー全体を通じて、Copilot を使って機能を計画、実装、検証しました。Tailspin Toys は、マージの承認を開発者の管理下に置きながら、残りの PR 作業を自動化したいと考えています。

## Agent Merge について

**Agent Merge** は、GitHub Copilot app で pull request を取り込むまでに必要な残りの作業を自動化します。有効にすると、アプリのセッションが pull request を読み取り、失敗した継続的インテグレーション (CI) チェックの修正、レビューコメントへの対応、必要に応じたリベースなど、マージを妨げている問題に対処します。GitHub で許可され次第、pull request をマージします。バックグラウンドで実行され、アプリを再起動しても継続し、pull request がマージされると自動的に停止します。

これまでは、自分で **Merge pull request** を選択していました。Agent Merge にその役割を任せることもできますが、コードの編集やマージには引き続き明示的な承認が必要です。マージ権限を与える前に、許可される操作と作業内容を確認してください。

## Agent Merge で PR を管理する

コードの作成とレビューが完了したら、Agent Merge に PR のプロセスを管理させます。

1. エージェントピッカーで **Default agent** を選択します。
2. **Create PR** の横にあるドロップダウンを選択します。
3. **Agent Merge** を選択します。ボタンが **Agent Merge** に変わります。
4. **Agent Merge** ボタンを選択してプロセスを開始します。ドロップダウンからオプションを選ぶだけでは開始されません。

Agent Merge が開始され、次の処理を行います。

- タイトルと説明を含む pull request を作成します。
- Issue からセッションを開始した場合は、説明の本文で関連する Issue を参照します。
- ターゲットブランチにリベースするか、マージ競合に対処します。
- CI を監視し、すべてのチェックが成功することを確認します。
- 他の開発者や Copilot code review からのフィードバックがないか PR を監視し、コメントを解決するために更新します。
- 必要に応じて、すべての処理が成功した後に PR を自動的にマージします。

すべてのチェックが成功したら、Agent Merge に PR もマージさせましょう。

5. マージを許可する前に、PR の差分と検証結果をレビューします。
6. **Agent Merge** の横にあるドロップダウンを選択します。
7. **Merge pull request** の横にチェックが付いていることを確認します。
8. エージェントに明示的にマージを依頼します。

    ```plaintext
    必須のチェックと承認がすべて成功したら、PR をマージしてください。リポジトリの保護を回避しないでください。
    ```

9. 進行状況を確認し、報告された問題を解決します。続行する前に、PR のステータスが **Merged** になっていることを確認します。マージ権限が有効になっていることや、エージェントが実行中であることだけでは、マージ完了の確認にはなりません。

> [!IMPORTANT]
> Agent Merge は、リポジトリの保護や権限不足を回避しません。続行する前に、これらの問題を解決してください。
